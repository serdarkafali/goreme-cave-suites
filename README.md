# Göreme Cave Suites — Web Sitesi

Göreme Cave Suites otelinin tek sayfalık web sitesi (v4). GitHub Pages üzerinden yayınlanır.

- `index.html` — sitenin tamamı (Odalar, Restoran, Hamam bölümleri dahil)
- `goreme-hero.mp4` — giriş bölümündeki arka plan videosu
- `.nojekyll` — GitHub Pages'in dosyaları olduğu gibi sunması için

Yerelde görmek için `index.html` dosyasını tarayıcıda açmanız yeterli.
